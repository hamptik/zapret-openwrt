# zapret-openwrt FDY — автообновление стратегий Flowseal

FDY — набор скриптов-дополнений к пакету **zapret**, которые автоматически:

- скачивают новые релизы [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube);
- конвертируют `.bat`-стратегии релиза в параметры `NFQWS_OPT`;
- проверяют стратегии «вживую» и выбирают лучшую;
- применяют победителя и (опционально) перезапускают zapret.

Zapret не является VPN — это Anti-DPI утилита. FDY не заменяет zapret, а управляет его стратегиями.

## Как это работает

```
       Flowseal (GitHub releases: zip + sha256)
                       │
                       ▼
  ┌─────────────────────────────────────────────────┐
  │ fdy-sync.sh        (cron / LuCI / вручную)      │
  │ скачать → проверить sha256/валидность →         │
  │ распаковать в /opt/zapret/fdy/current/          │
  └───────────────────────┬─────────────────────────┘
                          ▼
  ┌─────────────────────────────────────────────────┐
  │ fdy-convert.sh                                  │
  │ .bat-файлы релиза → fdy/strategies/*.opt        │
  └───────────────────────┬─────────────────────────┘
                          ▼
  ┌─────────────────────────────────────────────────┐
  │ fdy-test.sh                                     │
  │ цели из fdy/targets.txt (curl / PING),          │
  │ стратегии применяются по очереди «вживую»       │
  └───────────────────────┬─────────────────────────┘
                          ▼
  ┌─────────────────────────────────────────────────┐
  │ лучшая стратегия → NFQWS_OPT (config) →         │
  │ restart zapret   (fdy.sync.restart_after)       │
  └─────────────────────────────────────────────────┘
```

| Скрипт | Назначение |
|---|---|
| `/opt/zapret/fdy-lib.sh` | общие функции: UCI, логирование, защита от параллельного запуска |
| `/opt/zapret/fdy-sync.sh` | загрузка релиза Flowseal, проверка sha256, распаковка; `--cron` — тихий режим |
| `/opt/zapret/fdy-convert.sh` | конвертация `.bat` → `fdy/strategies/*.opt` |
| `/opt/zapret/fdy-test.sh` | живой тест стратегий по целям из `fdy/targets.txt`, выбор лучшей |

## Установка

Устанавливается **поверх стандартного пакета** этого форка (`zapret` + `luci-app-zapret`). Пакеты форка имеют версию `73.x`, чтобы отличаться от upstream (`72.x`):

```
opkg install zapret_73.*.ipk luci-app-zapret_73.*.ipk
```

Состав FDY в системе:

```
/opt/zapret/
├── fdy-lib.sh          # общие функции
├── fdy-sync.sh         # загрузка релиза (cron: fdy-sync.sh --cron)
├── fdy-convert.sh      # .bat → strategies/*.opt
├── fdy-test.sh         # живой тест стратегий
└── fdy/
    ├── targets.txt     # цели проверки (дефолт: 16 целей)
    ├── current/        # текущий (последний валидный) дистрибутив Flowseal
    ├── strategies/     # сконвертированные стратегии *.opt
    ├── logs/           # журналы sync/convert/test
    └── results/        # результаты тестов
```

- `fdy-*.sh` копируются правилом `$(CP) ./*.sh` из `zapret/Makefile` — отдельной настройки не требуют.
- `fdy-targets.txt` устанавливается как `/opt/zapret/fdy/targets.txt` (только если исходник присутствует в пакете).
- Рабочие каталоги `fdy/*` создаются при первом запуске скриптов.
- Настройка — через UCI (`/etc/config/zapret`, см. ниже) или вкладку LuCI.

⚠️ Обновление пакета перезаписывает дефолтный `targets.txt`. Свой список целей держите в отдельном файле и укажите его в опции `test.targets`.

## Настройка (UCI)

Файл `/etc/config/zapret`: тип секции — `fdy`, имена секций — `sync`, `test`, `general`.

```
config fdy 'sync'
	option enabled '0'
	option time '04:30'
	option mirror ''
	option autotest '1'
	option restart_after '1'

config fdy 'test'
	option curl_timeout '5'
	option start_wait '3'
	option max_parallel '4'
	option targets '/opt/zapret/fdy/targets.txt'

config fdy 'general'
	option gamefilter '0'
```

### fdy.sync — автообновление

| Опция | Дефолт | Описание |
|---|---|---|
| `fdy.sync.enabled` | `0` | включить автообновление релизов Flowseal |
| `fdy.sync.time` | `04:30` | время ежедневного запуска `HH:MM` (влияет на строку cron) |
| `fdy.sync.mirror` | *(пусто)* | зеркало для скачивания; пусто = официальный GitHub |
| `fdy.sync.autotest` | `0` | после синка запускать fdy-test и применять лучшую стратегию |
| `fdy.sync.restart_after` | `0` | перезапускать zapret после применения новой стратегии |

### fdy.test — тестирование

| Опция | Дефолт | Описание |
|---|---|---|
| `fdy.test.curl_timeout` | `5` | таймаут curl на одну цель, сек |
| `fdy.test.start_wait` | `3` | пауза после применения стратегии перед замером, сек |
| `fdy.test.max_parallel` | `4` | сколько целей проверять одновременно |
| `fdy.test.targets` | `/opt/zapret/fdy/targets.txt` | файл списка целей |

### fdy.general

| Опция | Дефолт | Описание |
|---|---|---|
| `fdy.general.gamefilter` | `off` | `all`/`tcp`/`udp` = nfqws обрабатывает диапазон портов `1024-65535` («игровые» порты). Заметно нагружает CPU на слабых роутерах |

Пример включения:

```
uci set fdy.sync.enabled='1'
uci set fdy.sync.time='05:00'
uci commit fdy
```

## Cron

При `fdy.sync.enabled=1` в `/etc/crontabs/root` поддерживается строка:

```
30 4 * * * /opt/zapret/fdy-sync.sh --cron
```

(`30 4` соответствует `fdy.sync.time=04:30`). Выключение — `fdy.sync.enabled=0`, строка cron при этом должна быть удалена. Ручная правка:

```
vi /etc/crontabs/root        # или crontab -e
/etc/init.d/cron restart
```

Ручной запуск с выводом в консоль — без параметра `--cron`:

```
/opt/zapret/fdy-sync.sh --force
```

## Сценарии отказа

| Сценарий | Поведение |
|---|---|
| **Нет сети / GitHub недоступен** | fdy-sync завершается с ошибкой в лог; текущий `NFQWS_OPT` и конфигурация не изменяются — zapret продолжает работать со старой стратегией |
| **«Кривой» релиз** | проверка sha256 (если опубликован) и валидация структуры дистрибутива; провал → релиз не применяется, остаётся предыдущий. Конвертация выполняется во временном каталоге, замена атомарная; при ошибке — откат к прежним `fdy/strategies/*.opt` |
| **Тест прерван** (reboot, питание, Ctrl-C) | trap-обработчики fdy-test.sh восстанавливают исходную стратегию и подчищают временные файлы/правила — система не остаётся с «полуприменённым» конфигом |

## Ограничения

- **Тест «мигает» интернетом.** fdy-test применяет стратегии поочерёдно на живой системе — в LAN на несколько секунд может деградировать трафик. Запускайте тест вне активного использования (дефолтный cron — ночь).
- **gamefilter (1024-65535) нагружает CPU.** На слабых роутерах (одноядерные MIPS) обработка почти всего диапазона портов может вызвать потери пакетов.
- **curl без TLS.** Если curl собран без поддержки HTTPS, HTTPS-цели пропускаются и тест деградирует до HTTP- и PING-целей — результат менее показателен. В стандартном OpenWrt curl собран с TLS.
- **PING-цели не показательны**: ICMP может блокироваться провайдером; недоступность `1.1.1.1` не всегда означает плохую стратегию.
- Формат `.bat` в Flowseal может измениться в любом релизе — тогда потребуется обновление конвертера.

## Ручная проверка без роутера

Конвертер и синтаксис скриптов можно проверить на обычном Linux/macOS, без OpenWrt:

```
# 1) синтаксис всех fdy-скриптов
cd zapret
for f in fdy-lib.sh fdy-sync.sh fdy-convert.sh fdy-test.sh; do sh -n "$f" && echo "OK: $f"; done

# 2) конвертация батников в стратегии
#    FDY_BASE перенаправляет рабочий каталог (по умолчанию /opt/zapret/fdy)
FDY_BASE=/tmp/fdy-check
mkdir -p "$FDY_BASE"
unzip ~/Downloads/flowseal-*.zip -d "$FDY_BASE/flowseal"
FDY_BASE="$FDY_BASE" ./fdy-convert.sh "$FDY_BASE/flowseal"
ls -l "$FDY_BASE/strategies"/*.opt
```

При заданном `FDY_BASE` скрипты работают только с указанным каталогом и не трогают систему. Точный синтаксис вызова и переменные окружения описаны в шапке каждого скрипта.
