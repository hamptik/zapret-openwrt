# Настройка DoH для всей локальной сети

## Установка ipk-пакета для DoH

Откройте WEB-панель для управления OpenWrt и перейдите на страничку **System / Software**.

**Примечание:** перед установкой ipk-пакетов нужно загрузить из сети списки всех доступных ipk‑пакетов (см. выше о кнопке **"Update Lists..."**).

Далее активируйте фильтрацию (режим filtered) и активируйте вкладку **Available** (см. скриншот).

![image](https://github.com/user-attachments/assets/527b6a28-c371-4819-84f0-d765516aa42e)

В поле **Filter** введите значение "dns-proxy" и после этого должно в списке отобразиться 3 ipk‑пакета (см. скриншот), которые необходимо установить (используйте кнопку **Install**).

После установки этих ipk-пакетов у них изменится статус на **Installed**:

![image](https://github.com/user-attachments/assets/95d90eb6-3d95-4e4e-8cba-303e395063e4)

После установки выше указанных ipk‑пакетов нажмите в основном меню OpenWrt раздел **Logout** и заново залогиньтесь. После этого в меню **Services** появится раздел **HTTPS DNS Proxy**.

Основная вкладка пакета **HTTPS DNS Proxy** выглядит так:

![image](https://github.com/user-attachments/assets/3caadc5d-8697-4acd-8917-08ff7b0c6b63)

**Примечание:** Кнопка **Enable** должна быть неактивной (если она активна, то нажмите её).

**Примечание:** Кнопка **Start** должна быть неактивной (если она активна, то нажмите её).

Если в процессе возникают проблемы с DNS/DoH, то будет полезно попробовать перезапустить данный модуль. Для этого достаточно нажать кнопку **Restart.**

# Настройка DNS в браузере Chrome

Откройте окно настроек в браузере Chrome, перейдите в раздел **Конфиденциальность и безопасность** и активируйте раздел **Безопасность.**

![image](https://github.com/user-attachments/assets/d3355193-8eae-44f2-ba9f-dcb0ac1d70ea)

На против поля **Поставщик услуг DNS** укажите "поставщика по умолчанию" (т.е. настройка текущего соединения с вашим роутером).

![image](https://github.com/user-attachments/assets/b6c656fa-3172-4ecf-9058-0c79b0689068)

# Проверка настроек сетевого соединения с роутером

На вашем устройстве, с которого вы настраиваете OpenWrt, активируйте список доступных для подключения сетей и перейдите в свойства активного подключения (оно должно использоваться для доступа к сети интернет через ваш роутер):

![image](https://github.com/user-attachments/assets/b5f2bf25-b99f-48e8-8500-c4913c7bd826)

В появившемся окне, содержащем информацию о сетевом подключении, нажмите кнопку **Редактировать** и в появившемся окне выберите **DHCP.**

![image](https://github.com/user-attachments/assets/e85ca4d1-9299-479f-baab-6ed326acdcbc)

После этих настроек все DNS запросы, идущие с этого устройства, будут проходить через модуль https‑dns‑proxy, который вы установили на роутере.
